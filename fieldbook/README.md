Question

Can messy research evidence become computationally useful without losing its identity as evidence?

Try this

Start with a source record.

Inspect the original material.

Then follow the record as information is:

acquired
extracted
normalized
compared
used in an observation
Watch for
The source remains available

The normalized record does not replace the original source.

You should be able to move backward toward the evidence.

Normalization is limited

The system transforms values where comparison requires it.

It does not attempt to turn every feature of the source into a universal ontology.

Missing information stays missing

The system should not silently invent values merely to complete a schema.

Observation and interpretation remain distinguishable

A computational observation such as:

County A reports a substantially higher value than County B.

is different from an explanation such as:

County A's policy caused the difference.

The latter requires additional evidence.
